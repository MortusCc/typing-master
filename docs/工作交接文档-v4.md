## 一、项目概况

打字学习网页应用 — React 19 + TypeScript + Vite + TailwindCSS 4 + Zustand + Dexie.js (IndexedDB)

- Cloudflare Pages 从 `main` 分支自动构建
- `public/_redirects`: `/* /index.html 200` 处理 SPA 路由

## 三、未解决的两个问题

### 问题 1: 计划面板自定义数量输入框无法手动输入

**根因**: WordTypingPage 全局 keydown 处理器拦截了所有单字符按键:
```typescript
if (e.key.length === 1) {
  e.preventDefault(); // 阻止了输入框中的字符插入
}
```
**建议修复**: 在单字符处理前检查焦点是否在自定义输入框。

### 问题 2: 首页最近练习记录无法继续

**根因**: IndexedDB 中旧 session 记录缺少 materialId 字段。
**当前状态**: Dashboard 已恢复稳定版本 (cdd1529), 显示"最近素材"而非"最近练习记录"。
**建议实现**: 过滤 `s.materialId` 为空的记录, 点击时 navigae 到 `/word?material=${s.materialId}`。

## 四、构建部署

- 每次 push 到 main 分支自动触发 Cloudflare 构建
- 命令: `npm run build` (= `tsc -b && vite build`)
- `noUnusedLocals: true` 会阻断未使用变量的构建
- 手动触发: Cloudflare Dashboard -> Pages -> 项目 -> 重试部署
