## 需求详细设计

### 需求 1：Excel 导入行数范围

改动：
- XlsxImporter.tsx：新增 endRow 状态（0=全部），在 mapping 步骤添加结束行输入框
- xlsxParser.ts：extractWordEntries 支持 endRow 参数

### 需求 2：文本导入格式说明

改动：
- TextImporter.tsx：在导入步骤上方添加说明卡片，附带格式例子

### 需求 3：中断保存进度 + 实时统计

改动：
- typingStore：新增 backspaceCount, totalKeystrokes, saveProgress(), restoreProgress()
- 使用 localStorage 存储当前会话
- 页面加载时检测未完成会话，询问用户是否恢复
- StatsBar 新增：退格数/总敲击数、单词正确率

### 需求 4：错误阻止前进

- 单词模式：submitWord 中若错误，不 advance()，清空重新打当前词
- 文章模式：Enter 前检查 errorIndices.size > 0，有错阻止跳段

### 需求 5：单词仅 Enter + 错误回弹

- 移除空格键 submitWord 触发
- 仅 Enter 触发判定
- 错误时清空输入重新打当前词

### 需求 6：单词定制计划

- WordTypingPage 选择素材后弹出计划面板
- 用户选择每次词数（20/30/50/100/全部）
- 新建 planStore 追踪：计划总数、已完成数、每批成绩
- 下次打开自动续接

### 需求 7：三年级单词音标表内置导入

- 复制 xlsx 到 public/default-materials/
- defaultMaterialsRegistry 新增 2 条目（三上/三下）
- buildMaterial 需支持 sheetIndex 参数

### 需求 8：拆分四+五上词汇表

- defaultMaterialsRegistry 新增 2 条目（四上/五上）
- buildMaterial 需支持 startRow/endRow 参数
